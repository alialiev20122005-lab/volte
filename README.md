# VOLTÉ — Премиальный интернет-магазин техники

> **VOLTÉ** — *Технологии в совершенной форме.*

Полнофункциональный современный интернет-магазин флагманской потребительской электроники, аудиотехники и премиальных аксессуаров. Разработан с нуля в соответствии с высокими стандартами современного e-commerce и минималистичной эстетикой люксовых технологических ритейлеров.

---

## 🌟 Ключевые возможности

### 1. Каталог и интеллектуальная фильтрация
- **24 реалистичных товара** в 6 ключевых категориях:
  - 📱 **Смартфоны** (Apple iPhone 16 Pro Max, Samsung Galaxy S24 Ultra, Google Pixel 9 Pro, Nothing Phone 2)
  - 💻 **Ноутбуки** (Apple MacBook Pro 16 M3 Max, MacBook Air 15, Dell XPS 16, ASUS Zenbook Duo)
  - 🎧 **Наушники** (Sony WH-1000XM5, Apple AirPods Max, Bang & Olufsen Beoplay H95, Bose QuietComfort Ultra)
  - 📱 **Планшеты** (Apple iPad Pro 13 M4 OLED, Samsung Galaxy Tab S9 Ultra, iPad mini 7, reMarkable Paper Pro)
  - 🎮 **Игровые устройства** (Valve Steam Deck OLED, Sony PlayStation Portal, DualSense Edge, ASUS ROG Ally X)
  - ⌚ **Аксессуары** (Apple Watch Ultra 2, Mophie 3-in-1 MagSafe, Nomad Horween Leather Case, Anker Prime 250W)
- **Поиск в реальном времени** по названию, бренду, описанию и категории.
- **Фильтрация**:
  - по категориям через интерактивные вкладки;
  - по диапазону цен (от / до);
  - по наличию («Только в наличии»).
- **Сортировка**:
  - по популярности и рейтингу;
  - сначала доступные (по возрастанию цены);
  - сначала премиальные (по убыванию цены);
  - новинки;
  - по названию (А–Я).
- **Переключение вида отображения**: сетка карточек (Grid) или подробный список (List).
- **Синхронизация с URL**: параметры поиска, категорий и сортировки сохраняются в URL query-параметрах (`?category=...&q=...&sort=...`).

### 2. Детальная карточка товара (`/product/:id`)
- Полноразмерная фотогалерея с интерактивным выбором миниатюр.
- Выбор цветовых модификаций устройства.
- Селектор количества (+ / -) с защитой от ввода меньше 1.
- Полная таблица технических характеристик.
- Подробное описание и перечень преимуществ (гарантия, экспресс-доставка, 30 дней на возврат).
- Блок сопутствующих рекомендаций из той же категории.

### 3. Локальная корзина (`/cart`)
- Добавление товаров с сохранением выбранного цвета.
- Изменение количества на лету с автоматическим пересчётом всех сумм.
- Удаление отдельных позиций и полная очистка корзины.
- Защита от отрицательного количества (минимум 1 единица).
- **Точные расчёты**: вычисления ведутся в целых рублях без погрешностей с плавающей запятой.
- **Бесплатная доставка**: автоматически рассчитывается при заказе от 50 000 ₽.
- Персистентность в `localStorage` — корзина не сбрасывается при перезагрузке страницы.

### 4. Избранное (`/favorites`)
- Мгновенное добавление и удаление товаров по клику на сердечко.
- Счётчик-бейдж в шапке сайта.
- Возможность массового переноса всех товаров из избранного в корзину в один клик.
- Сохранение состояния в `localStorage`.

### 5. Демонстрационный Checkout (`/checkout` и `/order-success/:orderId`)
- Валидация полей в реальном времени с выводом ошибок на русском языке:
  - Имя и фамилия (проверка длины);
  - Номер телефона (маска ввода `+7 (XXX) XXX-XX-XX` и проверка на 11 цифр);
  - Электронная почта (строгая regex-валидация email);
  - Адрес доставки (обязателен для курьера и экспресс-доставки, отключается для самовывоза).
- Выбор способа доставки:
  - «Курьерская доставка VOLTÉ» (590 ₽ / Бесплатно от 50 000 ₽);
  - «Экспресс-доставка за 3 часа» (1 490 ₽);
  - «Самовывоз из флагманского бутика» (0 ₽).
- Генерация уникального номера заказа (например, `VOLTE-2026-89412`).
- Экран подтверждения заказа со сводкой всех позиций, контактов и финальной стоимости.
- Очистка корзины после успешного оформления и запись заказа в локальную историю.
- Чёткие дисклеймеры о демонстрационном режиме во избежание недопонимания.

### 6. Дизайн-система и доступность
- **Светлая и тёмная темы** с сохранением пользовательского выбора в `localStorage`.
- Полная адаптивность: настольные ПК, ноутбуки, планшеты и мобильные смартфоны.
- Доступность: видимый фокус для навигации с клавиатуры, корректные ARIA-атрибуты.
- 100% русскоязычный интерфейс.

## 🛠 Технологический стек

- **Фреймворк**: React 19 + TypeScript
- **Сборщик**: Vite 8
- **Стилизация**: Tailwind CSS (с кастомной палитрой, эффектами матового стекла и тёмной темой)
- **Иконки**: Lucide React
- **Маршрутизация**: React Router DOM v7
- **Хранилище данных**: LocalStorage API с отказоустойчивой типизированной обёрткой
- **Тестирование**: Vitest + React Testing Library + JSDOM

## 🚀 Инструкция по запуску

### Предварительные требования
- Установленный **Node.js** (LTS v20+ или v24+) и **npm**.

### 1. Переход в папку проекта
```bash
cd volte-store
```

### 2. Установка зависимостей (если ещё не установлены)
```bash
npm install
```

### 3. Запуск сервера разработки
```bash
npm run dev
```
После запуска откройте в браузере локальный адрес: `http://localhost:5173`.

### 4. Запуск автоматических тестов
```bash
npm run test
```

### 5. Сборка для публикации (Production Build)
```bash
npm run build
```
Готовая оптимизированная сборка сформируется в папке `dist/`.

Для проверки сборки можно запустить локальный сервер предпросмотра:
```bash
npm run preview
```

## 🔒 Ограничения демонстрационного режима

1. **Платежи и сервер**: Магазин работает без внешнего бэкенда и платёжного шлюза. Все заказы создаются локально и сохраняются в `localStorage` вашего браузера.
2. **Изоляция**: Проект полностью изолирован в папке `volte-store`. Никакие сторонние репозитории или предыдущие проекты не затрагиваются.
3. **Юридический статус**: Все брендовые наименования, логотипы, цены и характеристики устройств носят демонстрационный характер и используются исключительно в целях демонстрации интерфейса.
