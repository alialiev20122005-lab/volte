# VOLTÉ — Инструкции для мультиагентной разработки и ролей

Проект VOLTÉ — это современный интернет-магазин премиальной техники ("Technology, refined").
Стек: React 19, TypeScript, Vite, Tailwind CSS, Lucide React, Vitest.

## Специализированные агенты проекта (короткие и полные имена):

1. **Разработчик (`dev` / `developer` / `volte-developer`)**:
   - Назначение: Разработка интерфейса и бизнес-логики интернет-магазина.
   - Права: Полный доступ (чтение, запись файлов, выполнение команд `npm test`, `npm run build`).
   - Правило: Сохранять архитектуру, проверять изменения тестами, соблюдать премиальный дизайн.
   - Как вызывать: Напишите в чате: *«Пусть разработчик (dev)...»* или *«Вызови dev...»*.

2. **Тестировщик (`qa` / `tester` / `volte-qa`)**:
   - Назначение: Независимое тестирование и аудит качества.
   - Права: Тестирование (чтение, запуск тестов Vitest и сборки).
   - Ограничение: **НЕ ИЗМЕНЯЕТ** код проекта без явного разрешения. Фиксирует дефекты со степенью критичности.
   - Как вызывать: Напишите в чате: *«Пусть тестер (qa)...»* или *«Вызови qa...»*.

3. **Дизайнер / UI-аудитор (`ui` / `designer` / `volte-ui-auditor`)**:
   - Назначение: Анализ визуальной иерархии, дизайн-системы, WCAG AA доступности и адаптивности.
   - Права: **Строго Read-Only**.
   - Ограничение: Формирует отчёт с указанием компонентов и классов, не меняет код.
   - Как вызывать: Напишите в чате: *«Пусть дизайнер (ui)...»* или *«Вызови ui...»*.

## Общие стандарты проекта:
- Язык общения: русский.
- Цены: только в рублях (₽).
- Никаких платных API, секретов и несанкционированных изменений.
